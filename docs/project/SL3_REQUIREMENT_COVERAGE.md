Final owner-debug correction: the former `work`, `work/{tab}`, and `work/{tab}/{filter}` destinations remain one optional-argument Work destination, but owner evidence showed route consolidation alone was insufficient. Commit `32dee7c` also proved insufficient because it retained navigation-triggered cancellation/generation ownership, a first-frame retained-row glimpse, and a cancellation path that could leave blocking loading true. The final architecture instead observes the authoritative Room projection once for the ViewModel lifetime. Work and New Visit share its atomic unresolved/available/error contract; authoritative empty is distinct from unresolved, claims remain visible, database mutations invalidate and update the query, and an error cannot erase last-good rows. The reusable long-text control remains an icon-only 24dp expand glyph in a 48dp target with `Expand text editor` accessibility semantics; its modal continues editing the same buffer and parent Save remains authoritative.
