## Shared identity rule

`BusinessProfile.technicianName` is the authoritative actual technician name used by service records and reports. Dispatch identity stores the stable installation identity and optional team designation/badge. The Member screen shows the report name read-only and links to Business and report identity; its Save action only persists the optional designation.

## Format and history rule

The `.sltech`, `.slinsp`, and `.slwork` decoders accept only their current format versions in this pre-release milestone. Historical reports, corrections, void notices, work-package generations, and imported immutable inspection snapshots are never silently rewritten by an export retry.
