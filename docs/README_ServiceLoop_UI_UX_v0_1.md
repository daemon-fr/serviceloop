# ServiceLoop — Conceptual UI/UX review package v0.1

**5 September 2026 · Proposal for review, not implementation approval**

## Start here

Extract the whole ZIP into one folder, then open **ServiceLoop_Conceptual_UI_UX_Design_v0_1.html** in a browser. Keep the companion files together: section, UI, action and original-source links use relative filenames. The main design and action appendix also have portable Markdown editions.

The main document contains sections A–J and the 59-surface catalogue. The separate **ServiceLoop_UI_UX_Action_Coverage_v0_1.html** is an integral appendix, not an optional sample: all **357 C actions and 375 F actions** have individual placements or explicit conflict dispositions. Use the contents filter to find UI identifiers or source parents. Tables and textual wireframes can scroll horizontally on small windows.

The reading editions are generated from the corresponding Markdown, have no required external assets, and do not need JavaScript to read their content. Official-reference links need an Internet connection. The reading document’s styling is not an additional proposal for the Android app’s theme.

## Authority and scope

C (`ServiceLoop_Conceptual_App_Map_v0_1`) remains the **recommended provisional working baseline**, not a user-adopted specification. F (`ServiceLoop_Complete_Functional_App_Map_v0_1`) is a distinct source proposal. The A/J registers identify 11 source conflicts/ambiguities and three explicit functional recommendations. A mapped F action does not imply that its conflicting behavior is active.

The original Markdown/HTML source pairs, original functional prompt and research context are included unchanged. The earlier partial design fragments are superseded for reading by the assembled main design and appendix; the source app maps are not superseded or overwritten.

## What the checks mean

`ServiceLoop_UI_UX_Delivery_Audit_v0_1.json` records source hashes, original action enumeration, anchor/link checks, 30 recomputed contrast-pair checks, fictional-example arithmetic and HTML rendering checks. `ServiceLoop_UI_UX_Contrast_Checks_v0_1.json` contains the exact pairs and ratios. The file manifest provides SHA-256 hashes for the delivered files.

The HTML was rendered from locally read content in the available Chromium environment, at wide and narrow viewports and in light/dark modes. Direct file-URL navigation was blocked by that environment’s browser policy; relative file/anchor targets were checked structurally instead. Ordinary downloaded-file navigation still depends on the recipient’s browser. No external assets were requested in those render tests.

These checks do not constitute an Android app, device/accessibility test, usability study, security review, generated-PDF/print test, Play approval or standards certification. Official-source access limitations and future validation tasks are explicit in section I. Fictional trade content is not an authoritative maintenance procedure.
